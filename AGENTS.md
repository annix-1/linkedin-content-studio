# Instructions for AI assistants (Codex, Cursor, Gemini, others)

Read [CLAUDE.md](CLAUDE.md) and follow it exactly. It applies to every assistant, not only Claude.

The short version: this project only works with the **Taplio LinkedIn MCP**. Before anything else, check that its `get_me` tool is available and returns the user's profile. If it isn't, stop and send the user:

- Setup video: https://www.youtube.com/watch?v=afjA8ifgo6A
- Get the Taplio LinkedIn MCP: https://taplio.com/taplio-linkedin-mcp
- MCP server URL for any client that supports remote MCP: `https://mcp.taplio.com`

Then continue with [SETUP.md](SETUP.md) once they confirm it's connected.
